# Метаболический профиль МА

Образовательный калькулятор: индексы инсулинорезистентности (HOMA-IR, TyG, ТГ/ЛПВП, Matsuda), секреция инсулина, гликемия и клинические признаки, сведённые в итоговую шкалу «Метаболический профиль МА».

- Языки: русский и английский
- Единицы: ммоль/л и мг/дл
- Пороги для женщин и мужчин
- Все расчёты выполняются в браузере, данные никуда не отправляются

Весь инструмент — один файл `index.html`. Открывается в любом браузере или публикуется через GitHub Pages.
